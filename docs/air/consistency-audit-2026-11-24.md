# Web family consistency audit

24 November 2026 · Air 1.8.1 audit and Air 1.8.2 release verification · Seven web builds

The audit found that a waiting app update covered the phone tool dock in CloakPDF and CloakIMG until dismissed. The seven homepages passed the same landing motion checks. The shared headers, footers and policy pages also passed their layout and navigation checks.

## Release verification — Air 1.8.2

The release candidates close all six findings below. PDF, IMG and Resume now place waiting-update feedback inside the visible preview, preserving access to toolbars and zoom controls. A real worker update was checked in all three editors at 320, 390, 768, 844, 1280 and 1440 px in light and dark. The notice remained dismissible. PDF and IMG also passed their separate work-preservation and activation regressions. [Updated editor screenshots](evidence/consistency-2026-11-24/update-notices-verified.jpg)

All 112 script-disabled entry checks now show content in the first viewport. IMG exposes its editor loader as a status and both IMG and Resume returned home after a failed lazy import. Roll’s installation heading now stands on its own. PDF compact Export retains its 44 px target and uses the filled primary style specified by Air. The release adds permanent checks for first-viewport fallback content and update notices over real editing controls. [Verified entry fallbacks](evidence/consistency-2026-11-24/fallbacks-verified.jpg)

Across both browser engines, all 132 editor views and 1,716 control-state comparisons now pass the strict family comparison, including compact Export.

The results below record the original Air 1.8.1 observations, before these fixes.

## Reproduction and limits

For the dock finding, open a disposable build with a fresh service worker, then open a PDF or image. Make a second version of the worker available and call the registration's normal update method. Once the second worker is waiting, use a 390 × 844 touch viewport. Compare the element at each dock button's center before and after dismissing the notice. The observation ledger includes the coordinates and the controls restored. For the entry findings, disable JavaScript before first navigation and inspect the first viewport before scrolling.

The public and privacy runners now use the configured policy route, handle current Chromium's computed alignment value and open a collapsed contents disclosure before activating its link. The editor runner opens PDF's current “All tools” control. Its strict reference comparison still flags compact PDF Export. Report-only mode completed the full two-engine matrix and preserved each difference.

Physical-device touch and software keyboards, OS input methods, spoken screen-reader output, Firefox, native macOS apps, installed-PWA launches and production deployments were outside this round. Cold AI model downloads and inference quality were also outside it. PDF tool selection covers every tool, with deeper output checks for the flows listed above. The document and image findings apply to the specified web builds.
